## 그동안 만든 공통 기능

- **공통 틀** `shared/tamheom.js`, `shared/tamheom.css` (지금 `?v=21`): 시작 → 짧은 설명 → 문제 → 끝 화면(개구리 스티커), 연잎 진행 표시, 난이도 자동 오르내림, 복습, 어른 설정.
- **소리**: 시작 `start`, 정답 `good_job`, 개구리 스티커 점프 `jump`, 끝 화면 `great`. 녹음 파일은 기기에만 넣고 저장소에는 올리지 않습니다. 크롬은 "Google 한국의" 목소리를 씁니다.
- **메인 페이지**: 학기 → 단원 → 활동 순서로 고릅니다. 활동의 🏠 버튼은 메인 첫 화면으로 갑니다.
- **화면 맞춤**: 13인치 아이패드 가로와 맥에서는 스크롤 없이 한 화면에 크게 보입니다. 아이폰(폭 700 이하 세로, 높이 500 이하 가로)에서는 그림 → 풀이 → 숫자 패드 순으로 쌓고 위아래 스크롤만 허용합니다 (공통 틀이 html에 `th-narrow`/`th-short` 클래스를 붙임, 2026-11-26 ?v=21). 새 활동도 아이폰 세로 402px에서 옆으로 넘치지 않는지 확인합니다.

## 정해진 규칙

- 문제 수준은 일반 3학년과 같게 합니다. 숫자 범위는 교과서에 맞추고 너무 큰 수는 쓰지 않습니다.
- 교과서 PDF(단원별)는 문제 유형과 숫자 범위만 참고합니다. 저장소가 공개라서 그림과 글은 옮기지 않습니다.
- 윗줄은 한 줄입니다. 질문도 한 줄입니다.
- 왼쪽에는 그림, 오른쪽에는 ①② 단계 박스를 두고, 그 옆에 최종 답 칸을 줄 높이에 맞춰 둡니다. 단계 박스는 처음부터 다 보여 줍니다.
- 자동 입력과 화살표는 쓰지 않습니다. 분수는 분모부터 씁니다.
- 확인 버튼은 숫자 패드 안에 있고, 맞히면 "다음 ▶"으로 바뀝니다.
- 안내 메시지는 화면 아래 가운데에 잠깐 뜹니다. 틀리면 칸을 바로 비웁니다.
- 회색 대신 연한 색을 씁니다.
- `shared/`를 고치면 모든 활동의 `?v=` 숫자를 하나 올립니다.
