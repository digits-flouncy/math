# 수학 탐험대 활동 만들기 가이드: 자폐 아동을 위한 근거 기반 방법

이 문서는 수학 탐험대의 새 활동을 만들거나 고칠 때 보는 체크리스트입니다. 대상은 초등 3학년(3-2학기) 아이이고, 문제 수준은 일반 3학년과 같게 유지합니다. 바꾸는 것은 **내용이 아니라 가르치는 방식**입니다.

> 근거 수준 표시: **[강]** 체계적 문헌고찰·메타분석에서 근거 기반으로 분류됨, **[중]** 연구가 있으나 수학·자폐 근거는 적음, **[실천]** 연구 결론을 웹 활동에 옮긴 우리 쪽 해석.

---

## 1. 핵심 원칙 7가지

### ① 명시적 교수: 보여주기 → 같이 하기 → 혼자 하기 **[강]**
- 자폐 학생 수학 문장제 연구 20편을 검토한 결과, **명시적 교수, 과제 분석, 최소 촉진 체계, 그래픽 조직자, 도식 기반 교수, 기술 보조 교수** 6가지가 근거 기반 기준을 충족했고, 보통 함께 묶어 쓰였습니다 (Root 외, 2021).
- 중도 장애 학생 수학 연구 24편 중 96%가 명시적 교수와 체계적 촉진·소거를 썼습니다 (Bowman 외, 2019).
- **활동에 적용:** 각 단계는 ⓐ 예시 1개를 화면이 직접 풀어 보여주고(개구리가 시범), ⓑ 힌트가 켜진 상태로 1~2문제, ⓒ 힌트 없이 혼자 푸는 문제 순서로 구성합니다.

### ② 구체물 → 그림 → 기호 (CRA) **[강]**
- 메타분석(33편, 효과크기 Tau-U = .91, 중~대)에서 효과적인 접근으로 **다중 표상**, 비디오 모델링, 도식 기반 교수, 반복 연습이 확인되었습니다 (Karal & Riccomini, 2024).
- 일반학급 자폐 아동에게 CRA를 적용해 덧셈·뺄셈·자릿값을 익히고 2~4주 뒤에도 유지된 사례가 있습니다 (Kaya & Yildiz, 2023).
- **활동에 적용 (분수):** 피자·막대를 직접 나누고 칠하기(조작) → 같은 그림에 숫자 표시(그림) → 그림 없이 `2/7`만(기호). 기호 단계에서 틀리면 **바로 이전 그림 단계로 돌아가** 보여줍니다.
- 분수는 피자(원)만 쓰지 말고 **막대와 수직선**도 씁니다. 수직선은 분수를 "크기를 가진 수"로 이해하게 하는 핵심 도구로 권고됩니다 (IES 분수 교수 실천 가이드, Siegler 외, 2010). "4는 14의 몇분의 몇" 같은 문제는 14개를 2개씩 묶은 그림(7묶음 중 1묶음 = 1/7, 4는 2묶음 = 2/7)으로 먼저 보여줍니다.

### ③ 과제 분석: 한 문제를 작은 단계로 쪼개기 **[강]**
- NCAEP는 972편 연구를 검토해 28가지 근거 기반 실천을 정리했고, **과제 분석, 시각적 지원, 촉진, 강화, 시간 지연, 비디오 모델링, 기술 보조 교수**가 포함됩니다 (Steinbrenner 외, 2020).
- **활동에 적용:** 어려운 문제는 단계 버튼으로 나눕니다. 예: "몇 개씩 묶을까? → 몇 묶음이 생겼지? → 4는 몇 묶음? → 분수로 쓰기". 각 단계를 맞혀야 다음 단계가 열립니다. 익숙해지면 단계를 하나씩 합쳐 줄입니다.

### ④ 오류 최소화: 촉진은 많이 시작해서 천천히 줄이기 **[강]**
- 촉진(prompting)과 시간 지연(time delay)은 NCAEP 근거 기반 실천입니다. 실패를 반복하면 틀린 답이 학습되고 좌절이 커집니다.
- **활동에 적용:**
  - 처음 보는 유형: 정답 후보에 은은한 강조 표시(가장 강한 힌트).
  - 다음 문제부터: 3~5초 기다렸다가 힌트가 나타나게(시간 지연), 점점 길게.
  - 틀렸을 때: "땡" 소리·빨간 X 대신 **차분하게 다시 보여주기** → 같은 유형을 바로 한 번 더 풀어 맞히고 끝나게 합니다.
  - 2번 연속 틀리면 난이도를 자동으로 한 단계 낮추는 옵션.

### ⑤ 예측 가능한 구조와 시각적 지원 **[강]**
- 시각적 지원은 NCAEP 근거 기반 실천입니다. 다음에 무엇이 오는지 알면 불안이 줄고 과제에 집중합니다.
- **활동에 적용:**
  - 모든 활동을 같은 틀로: **시작 화면 → 짧은 설명(예시 1개) → 문제 → 끝 화면**.
  - 화면 위에 진행 표시 (예: 연잎 10개를 개구리가 하나씩 건너감). "몇 문제 남았는지"가 항상 보이게.
  - 한 세션은 짧게 (예: 8~10문제). 끝이 정해져 있어야 합니다.
  - 버튼 위치·색·문구는 활동끼리 똑같이 유지합니다.
  - 지시문은 짧고 구체적으로: "알맞은 것을 골라 보세요"보다 "칠한 조각은 몇 개?".

### ⑥ 간격 복습과 섞어 풀기: "배웠는데 다음에 헷갈림" 대책 **[중]**
- 같은 유형을 한 번에 몰아 푸는 것보다 **시간 간격을 두고 다시 풀고**, 여러 유형을 **섞어 푸는 것**이 일반 학생의 수학 장기 기억에 더 효과적이라는 연구가 반복되었습니다 (Rohrer & Hartwig 정리). 자폐 아동만을 대상으로 한 연구는 적으므로 아이 반응을 보며 조절합니다.
- **활동에 적용:**
  - 매 세션 첫 2~3문제는 **지난번에 배운 것** (워밍업 복습).
  - 맞힌 유형은 1일 → 3일 → 7일 뒤 다시 나오게(브라우저 localStorage에 기록).
  - 처음에는 한 유형씩(오류 최소화), 정답률이 80% 이상이면 유형을 섞습니다. 섞기는 익숙해진 뒤에만.

### ⑦ 강화: 즉시, 구체적으로, 좋아하는 것으로 **[강]**
- 강화(reinforcement)는 NCAEP 근거 기반 실천입니다.
- **활동에 적용:**
  - 정답 즉시 음성 칭찬: "잘했어", "훌륭해", "대단해" 중 무작위 (아이가 좋아함). 가끔 "칠한 조각을 잘 셌어!"처럼 **무엇을 잘했는지** 말해 주기.
  - 개구리 캐릭터를 보상에 사용: 정답마다 개구리가 연잎을 점프, 세션 끝에 개구리 스티커 모으기.
  - 보상은 **노력과 과정**에도: 다시 시도해서 맞힌 경우에도 칭찬.

## 2. 감각 고려 체크리스트 **[실천]**
자폐 아동은 소리·빛·움직임에 민감한 경우가 많습니다. 아이마다 다르므로 부모가 끄고 켤 수 있게 만듭니다.
- [ ] 소리 켜기/끄기, 음량 조절 버튼
- [ ] 갑작스러운 큰 소리·깜박임·흔들림 효과 없음 (정답 효과도 부드럽게)
- [ ] 배경은 단순하게, 화면에 필요한 것만 (장식 최소화)
- [ ] 글씨 크게, 터치 영역 크게 (최소 48px)
- [ ] 시간 제한 없음 (타이머로 재촉하지 않기)

## 3. 부모 설정 화면에 둘 것
- 난이도 단계 선택 (1단계: 그림+힌트 → 마지막 단계: 기호만, 힌트 없음)
- 한 세션 문제 수
- 힌트 대기 시간 (0초 / 3초 / 5초 / 끔)
- 소리 켜기/끄기
- 간단한 기록: 날짜별 정답률, 자주 틀린 유형 (다음 복습에 반영)

## 4. 단원별 적용 예
- **5단원 분수 (분수만큼의 양, 여러 가지 분수, 크기 비교):** 피자 → 막대 → 수직선 순으로 표상을 넓힙니다. 크기 비교는 두 막대를 위아래로 나란히 놓아 눈으로 먼저 비교한 뒤 기호로 씁니다. 가분수·대분수는 "1판이 넘는 피자"처럼 그림으로 시작합니다.
- **6단원 그림그래프:** 개구리 아이콘 1개 = 10마리처럼 **단위 그림의 뜻**을 한 단계씩 확인합니다 (과제 분석). "알아보기 → 나타내기(직접 아이콘 끌어 놓기) → 해석하기" 순서를 교과서와 같게 유지합니다.
