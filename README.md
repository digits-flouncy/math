# 수학 탐험대 🧮

초등 3학년 수학 활동 모음입니다. GitHub Pages로 서비스됩니다: https://digits-flouncy.github.io/math/

## 폴더 구조

```
index.html                       메인 페이지 (활동 카드 목록)
3-2/                             3학년 2학기
  01-multiplication/             1단원 곱셈
    animal-legs.html             다리가 몇 개? (돼지와 오리)
  05-fractions/                  5단원 분수
    fraction-pizza.html          분수 탐험 (피자)
    fraction-part-whole.html     개구리 묶음 분수
  06-picture-graphs/             6단원 그림그래프 (준비 중)
shared/
  tamheom.css                    모든 활동이 같이 쓰는 모양 (색, 버튼, 키패드, 연잎 진행 표시)
  tamheom.js                     모든 활동이 같이 쓰는 진행 틀 (아래 참고)
docs/
  autism-teaching-guide.md       활동을 만들 때 따르는 교육 가이드
src/                             옛 주소 → 새 주소로 자동 이동하는 페이지만 있음 (지우지 마세요)
```

폴더 이름은 `<학년>-<학기>/<단원 번호 두 자리>-<주제>/` 입니다. 다음 학기는 `4-1/01-.../` 처럼 이어 붙입니다.

## 새 활동 추가하기

1. 단원 폴더(`<학년>-<학기>/<번호>-<주제>/`)에 HTML 파일 하나로 만듭니다. 새 단원이면 폴더를 새로 만듭니다.
2. 경로는 항상 **상대 경로**로 씁니다. 활동 페이지에서 메인으로 가는 링크는 `../../index.html` 입니다.
   (`/`로 시작하는 절대 경로는 Pages 주소 `/math/` 아래에서 깨집니다.)
3. 공통 틀을 씁니다: `<link rel="stylesheet" href="../../shared/tamheom.css">`, `<script src="../../shared/tamheom.js"></script>` 다음에 `Tamheom.activity({...})`. 기존 세 활동이 예시입니다.
4. `index.html`에 카드를 하나 추가합니다.
5. 파일을 옮길 때는 옛 위치에 `src/` 안의 파일처럼 자동 이동 페이지를 남겨 둡니다.

## 공통 틀 (shared/tamheom.js)

`docs/autism-teaching-guide.md`를 모든 활동에 똑같이 적용하는 틀입니다.

- **같은 순서:** 시작 화면 → 짧은 설명(예시 1개) → 문제 → 끝 화면(개구리 스티커)
- **연잎 진행 표시:** 몇 문제 남았는지 항상 보이고, 맞히면 개구리가 다음 연잎으로 뜀
- **음성 칭찬:** 정답이면 "잘했어!", "훌륭해!", "대단해!" 중 무작위로 브라우저 기본 목소리가 말함. 가끔 무엇을 잘했는지도 말함
- **틀렸을 때:** 빨간 X나 "땡" 대신 차분한 문구와 힌트. 두 번째에는 풀이를 그림으로 보여 주고 직접 맞히고 넘어감
- **난이도 3단계:** 어른 설정에서 시작 단계를 고름. 바로 3번 맞히면 한 단계 올라가고, 한 문제를 2번 틀리면 다음 문제가 한 단계 내려감 (둘 다 끌 수 있음)
- **복습:** 틀린 문제는 1일 → 3일 → 7일 뒤 다음 시작 때 먼저 나옴
- **화면 키패드:** 아이패드 키보드가 화면을 가리지 않음. 시간 제한 없음
- **어른 설정(⚙️, 시작 화면):** 시작 단계, 문제 수, 설명 보기, 힌트 대기 시간, 소리, 활동별 선택(예: 문제 종류), 날짜별 기록

설정과 기록은 그 기기의 브라우저에만 저장됩니다.
